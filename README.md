# Coffee Shop POS

Frontend foundation for the Coffee Shop POS and table-ordering platform described in `docs/prd.md`.

## Stack

- React 19 with TypeScript
- Vite 8
- Tailwind CSS 4
- shadcn/ui with the Nova preset
- Lucide React icons
- Motion for React (formerly Framer Motion)
- Oxlint

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

Add more shadcn components with:

```bash
npx shadcn@latest add <component>
```
